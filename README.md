# JemaBill — Official Public Website

Official marketing, utility billing catalog, and compliance portal for **JemaBill Technologies Limited**.

Designed for upstream provider compliance reviews (VTpass, Monnify, PaymentPoint, Hollatags, NaijaResultPins) and customer support.

## Live Website
- **GitHub Pages**: [https://theacj.github.io/jemabill-website/](https://theacj.github.io/jemabill-website/)

## Features & Services Covered
- **Electricity Bills**: Prepaid token generation & postpaid bills across all 11 Nigerian DisCos (IKEDC, EKEDC, AEDC, IBEDC, PHED, KAEDCO, KEDCO, EEDC, BEDC, YEDC, APLE).
- **Mobile Airtime & High-Speed Data**: Instant recharges across MTN, Airtel, Globacom (Glo), and 9mobile.
- **Cable TV Renewals**: Bouquet activations and renewals for DSTV, GOtv, StarTimes, and Showmax.
- **National Exam PINs**: Instant scratch cards and result checking tokens for WAEC, NECO, NABTEB, and JAMB UTME/DE.
- **Enterprise Bulk SMS**: Direct telecom carrier delivery with registered Sender IDs and DND bypass.
- **Interactive Verification**: Real-time customer registry name lookups before charging.
- **Zero Ambiguous Failures**: Automated reconciliation with 24/7 requery and instant wallet refunds on explicit failures.

## Compliance & Legal
- **NDPR Compliant**: Strict adherence to the Nigeria Data Protection Regulation and NDPA 2023.
- **No Fiat Remittances**: Strictly dedicated to authorized digital bill payments and utility aggregations.

## Tech Stack
- Responsive semantic HTML5 & modern CSS3
- Space Grotesk & Poppins Google typography
- Material Symbols Outlined icons (locally bundled)
- Vanilla JavaScript for real-time verification demos and dynamic interactive receipts
